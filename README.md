# Climex

A modern real-time analytics dashboard that consolidates multiple sources of live data into a single, intuitive platform. Climex provides users with interactive visualizations, dynamic charts, and meaningful insights to help monitor and compare global information in real time.

---

## Overview

Climex is a responsive analytics dashboard designed to transform real-time data into clear and interactive visualizations. The application presents information through charts, statistics, and an interactive world map, allowing users to explore and compare trends from a single interface.

Built with performance, scalability, and user experience in mind, Climex demonstrates modern frontend development, responsive design, asynchronous data handling, and data visualization techniques.

## Installation

Clone the repository

```bash
git clone https://github.com/kellasandyyyy1/climex.git
```

Navigate into the project directory

```bash
cd climex
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:3000
```

## How It Works

1. The dashboard loads when the application starts.
2. The application retrieves live data from external data providers.
3. The data is processed and formatted into a consistent structure.
4. Charts, statistics, and the interactive map are updated automatically.
5. Users can search, filter, and compare datasets in real time.
6. Reports and visualizations can be exported for offline use.
